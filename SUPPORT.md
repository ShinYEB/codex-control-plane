# Support

- Use GitHub Discussions for usage questions and design conversations.
- Use GitHub Issues for reproducible defects and scoped feature requests.
- Use private vulnerability reporting for security concerns.

RUVORA is pre-1.0 software. Before reporting a runtime problem, include the RUVORA version, Node.js version, operating system, relevant sanitized logs, and the smallest reproducible sequence. Do not publish credentials, private transcripts, or proprietary code.
